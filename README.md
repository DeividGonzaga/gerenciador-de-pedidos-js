# 🛒 Gerenciador de Pedidos

Projeto desenvolvido com **JavaScript puro** para praticar lógica de programação, manipulação de dados e operações assíncronas.

A aplicação simula um sistema simples de gerenciamento de pedidos de uma loja fictícia.

## 🚀 Funcionalidades

- Listagem de pedidos utilizando `map()`
- Busca de pedidos pelo ID com `find()`
- Validação de dados e tratamento de erros
- Filtragem de pedidos pendentes com `filter()`
- Cálculo do valor total dos pedidos com `reduce()`
- Simulação de consultas assíncronas com Promises
- Utilização de `async/await` para executar operações assíncronas

## 🧠 Conceitos praticados

- Arrays e objetos
- Funções e métodos de array
- `throw`, `try` e `catch`
- Promises
- `setTimeout()`
- `async/await`
- Tratamento de erros

## 🛠️ Tecnologias utilizadas

- JavaScript
- Node.js
